Bienvenido al repositorio de mi portafolio profesional. Este proyecto es una representación digital de mi trayectoria como **Ingeniero de Software** y **Desarrollador Web**, diseñado para mostrar mis habilidades, proyectos y experiencia de una manera moderna, interactiva y profesional.

## 🚀 Descripción

Este portafolio fue construido desde cero con un enfoque en **Clean Code**, **Diseño Responsivo** y **Experiencia de Usuario (UX)**. No se utilizaron frameworks pesados para la estructura principal, demostrando un dominio sólido de las tecnologías web fundamentales (HTML, CSS, JS).

El sitio cuenta con un diseño "Glassmorphism" moderno, modo oscuro/claro totalmente funcional y animaciones fluidas que guían al usuario a través de mi perfil profesional.

## ✨ Características Principales

- **Diseño Responsivo (Mobile-First):** Adaptable a cualquier dispositivo, desde teléfonos móviles hasta pantallas de escritorio.
- **Modo Oscuro / Claro:** Sistema de temas con persistencia de preferencias del usuario (LocalStorage) y detección automática del sistema.
- **Estilo Glassmorphism:** Uso de transparencias y desenfoques para una estética moderna y elegante.
- **Navegación Interactiva:** Menú móvil dinámico y resaltado de sección activa durante el scroll.
- **Animaciones:** Efectos de aparición (fade-in) al hacer scroll y micro-interacciones en botones y tarjetas.
- **Optimización:** Código minificado y estructurado para una carga rápida.

## 🛠️ Tecnologías Utilizadas

### Frontend
- **HTML5:** Estructura semántica y accesible.
- **CSS3:** Variables CSS (Custom Properties), Flexbox, Grid, Animaciones (@keyframes) y Media Queries.
- **JavaScript (ES6+):** Lógica del DOM, Intersection Observer API para animaciones y gestión del estado del tema.

### Herramientas y Recursos
- **Iconos:** Boxicons / Imágenes personalizadas.
- **Fuentes:** Google Fonts (Poppins & Inter).
- **Control de Versiones:** Git & GitHub.

## 🔧 Instalación y Uso

Para visualizar este proyecto en tu máquina local:

1.  **Clonar el repositorio:**
    ```bash
    git clone https://github.com/victor-huallpa/My-Profile.git
    ```
2.  **Navegar al directorio:**
    ```bash
    cd My-Profile
    ```
3.  **Abrir el archivo:**
    Simplemente abre el archivo `index.html` en tu navegador web favorito (Chrome, Firefox, Edge, etc.).

    *Opcional: Si usas VS Code, puedes usar la extensión "Live Server" para una mejor experiencia.*
